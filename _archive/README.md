# Archived case studies

SpotMe and Wellsmith, retired from the live site on 2026-10-02. GitHub Pages doesn't publish folders whose
names start with an underscore, so nothing in here is live. To bring a page back, move it (and its images)
back to the repo root and `images/work/`, then add a tile to `index.html` and entries to `sitemap.xml` and `llms.txt`.
