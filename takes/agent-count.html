Take #253735

Agent count is a flex, not a feature.

Yes, we run multiple autonomous agents. Most serious systems do. But the number is plumbing, the same way nobody cites their microservice count. Show the outcome, not the machinery. If someone wants to see which agent did what, it’s in the reasoning trace. Otherwise it’s noise.
